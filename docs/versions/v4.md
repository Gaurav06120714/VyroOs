# Vyro OS — v4.0 "Polish + Bug Hunt"

> **Theme:** Polish the desktop, fix real bugs, glassmorphism overhaul.
> **Sub-versions:** v4.0 → v4.14 (15 sub-versions).
> **Status:** ✅ Done before this session.

---

## What v4 is

v4 is the **polish-and-fix** release. After v3 added all the cryptographic
and networking heavy-lifting, v4 went back through every subsystem,
identified real bugs, fixed them, and overhauled the visual style with
proper glassmorphism — translucent panels, blur effects, accent-tinted
hover states, drop shadows that actually look right.

By the end of v4, the OS looks like a 2026-era macOS-inspired desktop
rather than a 1995-era flat color picker, and 7 real shipping bugs were
caught and fixed.

## What was built

### Glassmorphism overhaul
| Element | Polished |
|---------|----------|
| Window chrome | Translucent dark surface, 24px backdrop blur, accent-bordered |
| Dock | Glass panel with rounded corners, drop shadow |
| Top bar | Slim translucent strip with live RTC + status |
| Popovers | Quick settings + calendar + notification list on glass |
| Lock screen | Glass card centered with accent purple |
| Buttons | Suggested-action variant uses accent purple background |
| Notifications | Glass toast cards with drop shadow |

### Real bug fixes (7 shipped)

| # | Subsystem | Bug |
|---|-----------|-----|
| 1 | TLS | `key_share` extension OOB read during ClientHello parse |
| 2 | X.509 | Certificate `ext_len` overflow during DER walk |
| 3 | SMP | AP stack collision with PMM bitmap region |
| 4 | AEAD | Plaintext buffer overflow when ciphertext > capacity |
| 5 | HMAC | Garbage output when key length > block size |
| 6 | FAT32 | Cluster leak when overwriting partial directory entries |
| 7 | TLS | RX buffer stall after handshake completes |

### Desktop UX additions
| Feature | Description |
|---------|-------------|
| 6 wallpapers | Aurora, Sunset, Ocean, Forest, Night, Carbon |
| Clock widget | RTC-driven live time on desktop |
| Calendar widget | Month grid with today highlighted |
| Weather widget | Mock data, glass card |
| Theme toggle | Press 'T' anywhere to flip dark/light |
| Workspace pager | 4 virtual desktops via keys 1-4 |
| Lock screen | Press 'L' to lock, type password to unlock |

### Bootloader
- Sector budget bumped from 192 KB to 384 KB (24 → 48 chunks)
- Room for kernel to grow without re-engineering boot stage

### Userspace
- 2 sample user ELF binaries (user_init, user_hello)
- libvyro printf-lite for user programs
- ELF loader handles real programs

### Audio
- 5 PC speaker tunes + boot chime
- `bench` shell command
- `sched`, `halt`, `suspend`
