# Vyro OS — v7.0–v7.3 "Tri-Path Pivot"

> **Theme:** Fork Vyro into 3 concurrent product lines. Make the OS actually run.
> **Sub-versions:** 69 individual tags across vA.7.0–v7.3.1.
> **Status:** ✅ v7.3 done — current release (we are here).

---

## What v7 is

v7 is **THIS session**. After v6 honestly catalogued ~116 PM of remaining
work, v7 made a strategic decision: instead of grinding through one
linear path, **fork into 3 paths** that ship in parallel.

| Path | Identity | Base | Target |
|------|----------|------|--------|
| **Path A** | Vyro OS Desktop | Ubuntu 24.04 LTS remix | ~4 weeks to shippable ISO |
| **Path B** | Vyro OS Core | Linux kernel + Vyro userland | ~4 months to bootable image |
| **Path C** | Vyro Microkernel | from-scratch (the original) | continuing research |

v7 also made the OS **actually run end-to-end** — through 13 chained
hotfixes, the kernel went from "panics on first boot" to "renders the
Vyro OS 2.0 desktop lockscreen visibly".
