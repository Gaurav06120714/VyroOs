# Vyro OS — v2.0 "Desktop Edition"

> **Theme:** From a console-only OS to a full windowed desktop with apps.
> **Phases:** 31 → 50.
> **Status:** ✅ Done before this session.

---

## What v2 is

v2 takes the bare-kernel from v1 and turns it into a **modern desktop
operating system** — double-buffered compositor, themed widget toolkit,
app framework, and a full suite of 12 native applications.

By the end of v2, the OS boots from BIOS, runs the shell, accepts the
`gui` command, and switches into a graphical desktop with a dock, top bar,
draggable windows, theme toggle, notifications, control center, and a full
launchpad.

## What was built

### Compositor v2 (double-buffered)
| Feature | Description |
|---------|-------------|
| Back buffer | 1024×768×3 = 2.36 MB allocated from heap |
| Theme system | Dark + light variants, accent colors |
| Pixel ops | `comp_pixel`, `comp_rect`, `comp_border`, `comp_shadow`, `comp_glyph`, `comp_text`, `comp_gradient_v`, `comp_blur_rect` |
| `comp_present` | Blits back buffer to LFB in one pass |
| Glassmorphism | `comp_text_bg_alpha`, translucent overlays, blur primitives |

### Window manager
| Feature | Description |
|---------|-------------|
| Window struct | Position, size, title, focused, content |
| Traffic-light buttons | Close, minimize, maximize on title bar |
| Drag | Pick up window from title bar, move |
| Resize | Grip on bottom-right corner |
| Snap shortcuts | Keys 1-4 for halves/quadrants, key 0 for full |
| Drop shadows | Soft black halos around windows |

### Widget toolkit v2
| Widget | Description |
|--------|-------------|
| Button | Hover, active, suggested-action variants |
| Label | Plain text rendering |
| Panel | Glassy container with rounded corners |
| Toggle | On/off pill with sliding knob |
| Progress | Horizontal progress bar |
| List | Scrollable item list |
| Tile | Grid tile for launcher |

### App framework v2
| Feature | Description |
|---------|-------------|
| `app_ctx_t` | Per-frame render context (origin_x/y, width, height, mx/my, clicked) |
| App lifecycle | `init`, `render`, `event` callbacks |
| `apps_register_all` | Static registration of all 12 apps |
| Window placement | Cascading offset for new windows |

### The 12 native apps
| App | What it does |
|-----|--------------|
| **Files** | VyFS browser with toolbar, breadcrumb, status bar |
| **Settings** | 8 sections (General, Display, Personal, Accounts, Network, Security, Storage, About) |
| **Terminal** | Windowed shell with command history |
| **TextEdit** | Visual text editor over VyFS |
| **Calculator** | Big readable display with real RTC integration |
| **Clock** | Wall-clock + alarms |
| **Task Manager** | CPU/memory bars, process list |
| **Launchpad** | App grid launcher |
| **Notification Center** | Toast history |
| **Control Center** | Wi-Fi / Bluetooth / DND / AirDrop tiles, brightness + volume |
| **VyroBrowser** | Multi-window HTML renderer in a real app window |
| **App Store** | Graphical vyropkg with install buttons |

### Sockets + networking foundations
| Subsystem | Description |
|-----------|-------------|
| Berkeley sockets API | TCP state machine per RFC 793 |
| DHCP packet structures | (client implementation in v3) |
| DNS resolver | Hosts table + recursive lookup |
| IPC | Pipes, message queues, POSIX-style signals |

## Rules compliance

v2 goes beyond the `rulz/` guide — the rules cover Phase 0-7, v2 adds entire
desktop and IPC layers on top:

- ✅ Phase 7.1-7.7 all done in v1
- 🆕 Compositor / widget toolkit / 12 desktop apps (no rules equivalent)
- 🆕 Sockets API (rules' Phase 7.7 networking spec is implemented + extended)
- 🆕 IPC (pipes/queues/signals — Linux-style abstractions)

---

## What v2 does NOT have

- TLS / X.509 / cryptography (came in v3)
- Real-hardware AHCI / NVMe (came in v5/v6)
- Multi-path strategy (came in v7)
- Live boot from real USB stick (came in v6 via `make usb`)
