Vyro OS
Three paths APT repo GitHub

A small, honest desktop OS.

Vyro OS is built three ways in parallel: a real installable Ubuntu remix you can boot today, a Linux+Vyro userland image, and a from-scratch microkernel that boots from a 512-byte boot sector.

Download the latest ISO Browse the code

Path A — Ubuntu remix

Ubuntu 24.04 LTS underneath, Vyro on top. Glassmorphism GNOME theme, Plymouth splash, Calamares installer. Ships today.

vyro-os-7.x-amd64.iso

Path B — Linux + Vyro userland

Linux kernel via Buildroot. Vyro compositor owns DRM/KMS directly. libvyro, IPC, native apps. Working stack.

vyro-core-7.x.img

Path C — Microkernel

From-scratch 64-bit kernel. AHCI + NVMe + FAT32 + UEFI memory map. Hobby-grade research.

make && make usb

Get Vyro packages via apt

On a Vyro OS Path A install, get the latest apps from the official APT repo:

sudo apt install vyro-apt-source
sudo apt update
sudo apt install vyro-calculator vyro-files vyro-compositor
