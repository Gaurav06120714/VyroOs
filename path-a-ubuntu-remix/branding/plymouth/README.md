# Vyro Plymouth Theme

Boot splash for Path A. Renders a centered Vyro mark on `#0B0B12` with a
pulsing accent halo and a 5-dot progress indicator.

## Files

| File | Role |
|------|------|
| `vyro.plymouth` | Theme registration (read by `plymouth-set-default-theme`) |
| `vyro.script` | Animation script (Plymouth's scripting language) |
| `vyro-mark.png` | 256×256 Vyro logo (generated from `../logos/vyro-mark.svg` at build time) |
| `vyro-halo.png` | 384×384 soft accent glow (generated at build time) |
| `dot.png` | 12×12 dot for the progress row (generated at build time) |

## PNG generation (handled by live-build hook)

```bash
rsvg-convert -w 256 ../logos/vyro-mark.svg -o vyro-mark.png
# halo and dot are procedurally generated by branding/scripts/make-plymouth-assets.sh
```

## Install (in live-build)

The chroot hook `live-build/config/hooks/normal/0040-vyro-plymouth.hook.chroot`
copies this directory to `/usr/share/plymouth/themes/vyro/` and runs
`plymouth-set-default-theme -R vyro` to make it the default.

## Local preview

```bash
sudo cp -r . /usr/share/plymouth/themes/vyro/
sudo plymouth-set-default-theme -R vyro
sudo plymouthd --debug --no-daemon &
sudo plymouth show-splash
sleep 5
sudo plymouth quit
```
