# Vyro OS — v5.0 "Real-Hardware Foundations Begin"

> **Theme:** Detect real-world disk and network controllers, prepare for bare-metal.
> **Sub-versions:** v5.0 → v5.8 (9 sub-versions).
> **Status:** ✅ Done before this session.

---

## What v5 is

v5 is the first release where Vyro looks at **real PC hardware** rather than
just QEMU's simulated devices. Adds **AHCI** (modern SATA), **NVMe** (modern
SSDs), **Intel E1000** family Ethernet, **xHCI** USB 3.0 detection — the
controllers actually present on every PC sold since ~2010.

By the end of v5, the OS can probe PCI for AHCI/NVMe/E1000/xHCI controllers,
parse their config registers, read MAC addresses from EEPROM, and report
basic capabilities. It can also build a real **32 MB bootable USB image**
via `make usb`.

This is the release that crosses the line from "QEMU-only hobby OS" to
"could in principle run on real hardware".

## What was built

### AHCI SATA controller (v5.0)
| Step | Details |
|------|---------|
| PCI probe | Class 0x01 / subclass 0x06 / prog-if 0x01 |
| ABAR mapping | Reads BAR5 from PCI config space |
| GHC.AE enable | Sets AHCI enable bit |
| Capability parse | Reads CAP register — NP, NCS, 64-bit support |
| Port enumeration | Walks 32 ports, checks PORT_SSTS for det=3/ipm=1 |
| `ahci` shell command | Shows controller info + active ports |

### NVMe controller (v5.7 + v5.7.1 hotfix)
| Step | Details |
|------|---------|
| PCI probe | Class 0x01 / subclass 0x08 / prog-if 0x02 |
| BAR0 mapping | Handles 64-bit BAR with bits 1:2 == 10b |
| CAP register parse | MQES (max queue entries), DSTRD (doorbell stride) |
| VS register | Major/minor version |
| `nvme` shell command | MMIO base, version, max queue entries, doorbell stride |

### Intel E1000 NIC (v5.6)
| Step | Details |
|------|---------|
| PCI probe | Vendor 0x8086 + 12 known device IDs |
| Supports | 82540EM (QEMU default), 82545EM, 82574L, I217/I218/I219, I225, I210 |
| BAR0 mapping | MMIO base |
| MAC read | From RAL+RAH (0x5400+0x5404) — EEPROM auto-populated |
| Link status | STATUS register |
| `e1000` shell command | Device ID, MMIO base, MAC, link up/down |

### xHCI USB 3.0 controller
| Step | Details |
|------|---------|
| PCI probe | Class 0x0C / subclass 0x03 / prog-if 0x30 |
| Capability registers | Halt, reset, DCBAA setup |
| Command Ring | Cycle bit + RCS dance |
| Event Ring | ERSTBA / ERDP / event consumer |
| Enable Slot | Reaches "device addressed" state |
| (Full enum) | Deferred — capability layer only |

### HAL skeleton (v5.x)
```
kernel/arch/
  hal.h                — common HAL interface
  x86_64/hal_x86_64.c  — real CPUID parsing (vendor, brand, family, model, features)
  arm64/hal_arm64.c    — stubs (MIDR_EL1 + CNTVCT_EL0 read)
```

### ACPI table walker
| Step | Details |
|------|---------|
| RSDP discovery | EBDA scan + 0xE0000-0xFFFFF scan |
| RSDT / XSDT enumerate | Walks all SDTs |
| Table lookup | By 4-character signature |
| MADT walker | Reports Local APIC / IOAPIC list per real firmware |
| `acpi` shell command | Dump table info |

### `make usb` (v5.8)
| Output | What |
|--------|------|
| `build/vyro-usb.img` | 32 MB raw bootable image |
| Boot sector at LBA 0 | 512 bytes |
| kernel.bin at LBA 1+ | Zero-padded |
| Output instructions | Prints exact `diskutil` + `dd` sequence for macOS |
| `docs/USB_INSTALL.md` | Compatibility table: BIOS PCs ✅, pre-T2 Intel Macs ⚠️, T2/Apple Silicon ❌ |
