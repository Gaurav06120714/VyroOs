# Vyro OS — v1.0

> **Theme:** The first real 64-bit kernel that boots and runs a shell.
> **Phases:** 0 → 30 (per the OS build guide).
> **Status:** ✅ Done before this session.

---

## What v1 is

v1 is Vyro OS as a **bare bones 64-bit operating system written entirely from
scratch** — no Linux, no BSD, no existing kernel. Every line is NASM + C.

By the end of v1, the OS boots from a 512-byte boot sector, enters 64-bit
long mode, runs C code, manages memory with a real first-fit allocator, has
a working shell with command history, and supports user-mode programs.

---

## What was built

| Subsystem | Description |
|-----------|-------------|
| Bootloader | 512-byte BIOS boot sector, loads kernel from disk via int 0x13 |
| Protected mode → Long mode | GDT, IDT, switch to 32-bit then 64-bit |
| Paging | PML4 + PDPT + PD identity-mapping (0-4 GB) |
| Cross-compiled C kernel | `x86_64-elf-gcc` with `-ffreestanding -nostdlib` |
| VGA screen driver | Text-mode 80×25 at 0xB8000, scrolling, color |
| Framebuffer driver | Linear framebuffer (LFB) via VBE mode 0x118 (1024×768×24bpp) |
| Keyboard driver | PS/2 IRQ1 with scancode-to-ASCII table |
| PIT timer driver | 100 Hz tick, sleep_ms support |
| RTC driver | Real-time clock for wall-clock time |
| IDT + ISRs | All 32 CPU exceptions wired up, panic screen |
| PIC remap | IRQ 0-7 → INT 32-39, IRQ 8-15 → INT 40-47 |
| PMM (physical memory manager) | Bitmap allocator at 0x100000 |
| Heap allocator | 8 MB heap at 0x500000, kmalloc/kfree with coalescing |
| VFS (virtual filesystem) | In-memory tree with first_child + next_sibling |
| FAT32 read-only driver | BPB parse, FAT walk, directory list, file read |
| ATA PIO disk driver | Persistent sector read/write |
| Scheduler | Cooperative round-robin |
| Syscalls | `int 0x80` with syscall table |
| User mode | Ring 0/3 split, TSS, GDT user descriptors |
| ELF64 loader | Load and execute user programs |
| Basic window manager | Compositor v1, draggable windows, traffic lights |
| Shell (v1) | help, ls, cat, echo, pwd, history, more |

## Rules compliance

v1 implements every rule from the `rulz/` guide:

- ✅ Phase 0 — Environment (nasm, qemu, cross-gcc)
- ✅ Phase 1 — Boot sector (512 bytes, 0xAA55, BIOS interrupts, disk read)
- ✅ Phase 2 — GDT + protected mode (then long mode beyond spec)
- ✅ Phase 3 — C kernel (freestanding, cross-compiled, linker script)
- ✅ Phase 4 — Drivers (VGA, I/O ports, scrolling)
- ✅ Phase 5 — Interrupts (IDT, PIC, timer, keyboard)
- ✅ Phase 6 — Shell + kmalloc
- ✅ Phase 7 — Advanced: paging, scheduler, syscalls, user mode, VFS

## What v1 does NOT have

- Desktop GUI (came in v2)
- TLS / networking stack (came in v3)
- Real-hardware drivers like AHCI/NVMe (came in v5/v6)
- Multiple paths (came in v7)
